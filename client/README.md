# Operation Vault Web Client (very much WIP)
This is the web client for Operation Vault. **It's still very much in development** and doesn't actually have any functionality yet but I'll be working on this. It'll be released as part of v1.0 consisting of two components, the web editor and reader.
## Web Editor
The web editor will be released first (I think, not sure yet to be honest). It'll essentially be glorified implementation of CodeMirror in the browser, so don't expect too much. I'll try my best to also implement the viewing and editing of Obsidian Canvas, Excalidraw files, etc. here.
## Web reader
This web reader will essentially act as an interface for the general public to view articles. It'll eventually act as an extension of a website (e.g. https://blog.example.com or https://example.com/casestudies) and allow the main Obsidian plugin to essentially act as a CRM system. The hope is that a user will be able to manage multiple feeds from one vault, while also using that same vault for daily use. I'm not quite sure if that sounded right but I'm essentially saying that I hope to make the CRM integration seamless and easy to manage.
